Conhecendo o Dom

O que e o DOM?

DOM significa Document Object Model.

E uma representacao do documento HTML em forma de objetos, organizada em uma estrutura hierarquica de arvore, comhecida como DOM Tree

Funciona como uma especie de arvore genealogica.

Note que cada elemento do HTML esta conectado. Chamamos em uma esses elementos de no (node) dentro dessa estrutura.

Em outras palavras, o navegador tranformar o HTML em uma estrutura que o JavaScript consegue acessar.

Pra que serve o DOM?

O DOM permite que o JavaScript interaja com os elementos em HTMl. Exemplos:

  • Selecionar elementos: Encontrar um botao
  • Alterar conteudo : Alterar um titulo, paragrafo...
  • alterar conteudo: Mudar cores, aplicar bordas e qualquer outro estilo do css
  • Criar elementos: Excluir itens criados e ja existentes
  • Capturar eventos : Detectar cliques, teclas pressionadas...
  • Modificar atributos: Alterar um Src, atributos aria e outros de modo geral...
